Detection Modules

Three pipelines. One verdict.

Each module targets a different attack surface. Together they make DeepShield adversarially robust — fooling all three simultaneously is practically impossible.

01 / Face Detection

EfficientNet-B4 Visual Analysis

MediaPipe extracts face crops from every video frame. EfficientNet-B4 — trained on FaceForensics++ and Celeb-DF-v2 — detects GAN artifacts, blending boundaries, and texture anomalies at AUC-ROC above 0.95.

EfficientNet-B4 MediaPipe FaceForensics++ Celeb-DF-v2
02 / Voice Analysis

AASIST Voice Spoof Detection

Log-Mel spectrograms and MFCCs feed the AASIST graph attention network fine-tuned on ASVspoof 2021. Detects TTS synthesis, voice conversion, and neural vocoder artifacts with EER below 5%.

AASIST ASVspoof 2021 MFCC CNN-LSTM
03 / Linguistic NLP

BERT Linguistic Pattern Analysis

BERT fine-tuned on HC3 (37,175 QA pairs) classifies AI-generated versus human text. Statistical fallback measures filler density, bigram entropy, and AI marker phrase detection — works fully offline.

BERT HC3 Dataset Bigram Entropy TF-IDF
04 / Risk Fusion

MLP Fusion Engine with XAI

A trained MLP combines Face (35%), Voice (35%), NLP (30%) with anomaly boosting. Returns a calibrated authenticity probability, confidence intervals, alert severity, and plain-English XAI evidence bullets.

MLP Fusion XAI Evidence Confidence Intervals WebSocket
How It Works

From upload to verdict in seconds.

Three AI pipelines run in parallel the moment a file is uploaded. Results stream live to your screen via WebSocket.

STEP 01

Upload Media

Drop a video, audio file, or paste text. Drag-and-drop supported. Any file type up to 500 MB.

STEP 02

3 Modules Run

Face, Voice, and NLP pipelines process simultaneously. Each gives an independent confidence score.

STEP 03

MLP Fusion

Weighted scores fused with anomaly boosting. Confidence interval computed based on module agreement.

STEP 04

Verdict + XAI

Calibrated score, severity alert (CRITICAL to CLEAR), XAI evidence bullets, and recommended action — all streamed live.

Adversarially robust by design

A criminal must fool three completely independent AI systems simultaneously — exponentially harder than bypassing any single-modality detector.

Offline fallback always works

All three modules include statistical heuristics that produce valid results without any trained model weights — the demo runs anywhere.

Live WebSocket streaming

Results appear on screen as each module completes — face score first, then voice, then NLP, then fusion — all without a page refresh.

Every decision is explainable

XAI evidence bullets explain each detection in plain English — which module flagged it, what triggered the flag, and what action to take.

Use Cases

Built for identity fraud that can't be allowed.

Wherever a deepfake video call, cloned voice, or AI-written script could cause real harm, DeepShield catches it.

Banking KYC Verification

Detect if the person on a video KYC call is a real human or an AI-generated deepfake impersonating a customer — before any account is opened.

Legal Evidence Integrity

Verify whether a video or audio recording submitted as evidence in legal proceedings has been manipulated or synthesised using AI tools.

CEO Fraud Prevention

Stop voice clone scams targeting finance teams. Detect synthetic executive voices on calls requesting urgent wire transfers — the exact attack that cost one firm $25 million.

Media & Journalism

Verify news videos and politician speeches before publication. Flag AI-generated or manipulated footage that could be mistaken for real reportage.

Telemedicine Security

Ensure that remote patient consultations involve real verified individuals — not deepfake proxies accessing sensitive medical records or prescriptions.

Enterprise Security

Protect board meetings and sensitive video calls from criminals who impersonate executives using AI-generated voice and face clones to authorise fraudulent transactions.
