Detection modules

Three pipelines.
One verdict.

01 — Face detection

EfficientNet-B4 Visual Analysis

MediaPipe extracts face crops from every video frame. EfficientNet-B4 — trained on FaceForensics++ and Celeb-DF-v2 — detects GAN artifacts, blending boundaries and texture anomalies. Target: AUC-ROC above 0.95.

EfficientNet-B4MediaPipeFaceForensics++Celeb-DF-v2
02 — Voice analysis

AASIST Voice Spoof Detection

Log-Mel spectrograms and MFCCs feed an AASIST graph attention network fine-tuned on ASVspoof 2021. Detects TTS synthesis, voice conversion and neural vocoder artifacts. Target: EER below 5%.

AASISTASVspoof 2021MFCCCNN-LSTM
03 — Linguistic NLP

BERT Linguistic Pattern Analysis

BERT fine-tuned on HC3 (37,175 QA pairs) classifies AI-generated vs human text. Statistical fallback measures filler density, bigram entropy and AI phrase markers — works completely offline.

BERTHC3 DatasetBigram EntropyTF-IDF
04 — Risk fusion

MLP Fusion Engine with XAI

A trained MLP combines Face (35%), Voice (35%) and NLP (30%) with anomaly boosting. Returns a calibrated score, confidence interval, alert severity and plain-English XAI evidence bullets via WebSocket.

MLP FusionXAI EvidenceCI ±8%WebSocket

Adversarially robust by design

A criminal must fool three completely independent AI systems simultaneously — exponentially harder than bypassing any single-modality detector.

Offline fallback always works

All three modules include statistical heuristics that produce valid results without any trained model weights — the demo runs anywhere, zero dependencies.

Live WebSocket streaming

Results appear on screen as each module completes — face score, then voice, then NLP, then fusion — all without a single page refresh.

Every decision is explainable

XAI evidence bullets explain each detection in plain English — which module flagged it, what triggered the flag, and what action to take.
